AI limitations noted so far:
- The AI estimated E2 at ~4.5 GPU-h on a T4 (D-013). On the Mac the measured cost was 334 s/topic, about 9 h, which led to PC-004.
- R1's retry honoured a `Retry-After` of about 8 h without saying so. The AI initially reported it as "still running" before diagnosing the exhausted daily allowance.
- The AI's first paper draft included an unverified parameter count for the NLI model and an inaccurate runtime claim. Both were removed in the cross-check before commit.
- The AI's first name parser (written before looking at the data) failed on 3 real answer formats. A pilot run with manual inspection caught this before any main-set result existed (D-017 #1).
- The AI's first oracle similarity (`token_sort_ratio`, proposed in Prompt 07) produced a false match on a reordered title. Replaced on pilot evidence (D-017 #3).
- The AI initially overlooked that NLI scores two refusals as consistent. This would have biased the judge comparison against J-NLI (D-017 #2).
- The roc-utils source showed that Agrawal's AUC auto-flips below-chance detectors. Copying that behaviour into our own experiments without noticing would have hidden inverted detectors. The rule is now explicit (D-016) and tested (`test_perfect_and_inverted`).
- The AI's first test assumed that every released file had 200 topics × 5 references. Running the test against the real file disproved that (D-014). The bug was in the data, not the code. This is a real example of verification catching an assumption.
- The original `check_pip` treated any conflict in the whole Colab image as a failure. That was too strict for a managed environment the AI did not control (D-012).
- The AI's Prompt 04 compute estimate (4–6 GPU-h for E2) was too low. Measured throughput gives ≈ 8.6 GPU-h for 190 topics (D-013).
- From the README alone, the AI first assumed that the generator would need to be run for every comparison. Inspecting the released CSVs showed that the samples already exist, and this changed the design (E1).
- The AI's first recommendation (Prompts 02–03) framed G1 as an open gap. Its own Prompt 04 search found prior work (Agrawal et al.) that had already shown this. The original framing would have overclaimed novelty. This is a real example for the Prompt 18 audit.

- The AI first assumed (Prompt 02) that the SelfCheckGPT dataset was GPT-3 WikiBio from memory. A fetch in Prompt 03 confirmed it and also showed that 20 samples per passage are included. This changed the plan because no generator is needed for the baseline.
- The Crossref documentation pages the AI fetched did not state access rules, so Crossref access is still UNKNOWN.
